Xiaoye Remote 3.0.1 Released: Easily Build Network Groups Across Accounts

May 12, 2026 · 3 min read
Author: XiaoyeApp

We are excited to announce that Xiaoye Remote 3.0.1 is officially released! This update brings a major new feature — Network Group — making cross-account device connectivity easier than ever before.

🚀 Core Highlight: Cross-Account Network Groups​

In the past, when using remote control software, devices under the same account could connect easily. However, once different accounts were involved, complex configurations, relay servers, or even third-party tools were often required.

Now, Xiaoye Remote Control 3.0.1 completely solves this problem.

A Network Group is a virtual device cluster that allows you to add devices from multiple different accounts into the same logical group, enabling direct cross-account connectivity with no additional configuration required.
