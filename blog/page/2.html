Xiaoye Remote 3.0.5: HTTP Sharing - A Simpler Way to Shre Files

July 1, 2026 · 4 min read
Author: XiaoyeApp

We are pleased to announce the official release of Xiaoye Remote 3.0.5! This update brings a highly anticipated core feature – HTTP Sharing – making file sharing between different devices simpler and more flexible than ever before.

What is HTTP Sharing?​

HTTP Sharing is a one-click file sharing feature provided by Xiaoye Remote. Once you start the service, you can add files to the mapping list, and others can easily access your shared files through the HTTP links you generate.

Wide range of applicable scenarios: Whether on a local network at home or in the office, through the virtual subnet built by Xiaoye Remote, or even in broader network environments, you can quickly achieve file sharing.
