WireGuard在Windows上的基本使用

2026年7月7日 · 阅读需 4 分钟
作者：小烨App

WireGuard 以其简洁、高效和安全性著称，在 Windows 平台上的官方客户端也延续了这一特点。与 Linux 下的命令行操作不同，Windows 版本更侧重于图形化管理与隧道切换，配置逻辑主要围绕生成密钥对和编辑.conf文件展开。

以下配置基于两台 Windows 设备，节点 A 拥有公网 IP（或已配置端口映射），作为“中心节点”等待连接；节点 B 处于内网，主动连接节点 A，实现两者互通。配置的核心逻辑是：A 负责“等待连接”，B 负责“找到 A”，这里的“等待连接”并非真正建立连接，而是B通过主动发送数据包并建立保活机制来维持二者之间的数据通道，当B主动发送数据包给A时，B也会在路由器公网端留下自己的外部端口，这样A也可以反向给B回应数据。

1. 前期准备：安装与生成密钥​

1-1. 两台 Windows 设备：节点 A（有公网 IP）、节点 B（在内网，能上网就行）。

1-2. 安装 WireGuard 客户端：目前官网被屏蔽，从国内一些软件网站上可以找到，但是要注意保证只在国内使用，比如从家里到公司这种，否则涉及跨境转发同样会被屏蔽。

1-3. 确认 A 的端口可达：A 上要放行一个 UDP 端口（比如6000），需要在 Windows 防火墙中添加入站规则。如果 A 前面还有路由器，需要在路由器上做端口映射，把公网 IP 的6000 映射到 A 的内网 IP。

1-4. 准备记录公钥：配置过程中需要互相复制对方的公钥，建议提前打开记事本备用。
